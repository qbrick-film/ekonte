# 絵コンテ作成ソフト

PDFに描いた**カット絵**のマークシートを読み取り、香盤表・カット表のExcel（1つのファイル）と組み合わせて、
次の2つを書き出すソフトです。

- **絵コンテ**（PDF）：S / C / PICTURE / ACTION/SE / SCENARIO / TIME / NOTE。すべて入った完成品
- **香盤表**（Excel）：カット絵以外のすべて。シーンごと（カット数・時間・小道具・カメラ・機材をまとめたもの）と、カットごとの2枚のシート

ブラウザ版とアプリ版があり、中身（読み取り・組み立て）は同じなので、どちらでも同じものができます。

## ブラウザで使う（おすすめ）

**https://qbrick-film.github.io/ekonte/** を開くだけで使えます。インストールは要りません。

- 処理はすべてブラウザの中で行います。カット絵やExcelは、どこにも送られません。
- 初めて開くときだけ、ブラウザで動く Python などを30MBほど読み込みます（数秒〜十数秒）。2回目からは速くなります。
- Chrome・Edge・Safari・Firefox の最新版で、パソコンから使ってください。
- 作ったファイルは、ブラウザの「ダウンロード」に保存されます。

## アプリで使う（ネットがない場所用）

右側の **Releases** から、いちばん新しい版の zip をダウンロードします。

| パソコン | ファイル |
|---|---|
| Mac（M1 以降の Apple シリコン） | `Ekonte-mac-apple-silicon.zip` |
| Mac（Intel） | `Ekonte-mac-intel.zip` |
| Windows | `Ekonte-windows.zip` |

署名をしていないアプリなので、初めて開くときだけ確認が出ます。

- **Mac**：Ekonte.app を「アプリケーション」に移してダブルクリック →「開けません」と出たら閉じて、
  システム設定 →「プライバシーとセキュリティ」の下にある Ekonte の「このまま開く」を押します。
- **Windows**：zip を右クリック →「すべて展開」してから Ekonte.exe を開きます。
  「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」を押します。

**安全のために**

- アプリは、このリポジトリの Releases からだけ入手してください。ほかの場所で配られているものは、中身がすり替えられているおそれがあります。
- ブラウザ版の正しいアドレスは `qbrick-film.github.io/ekonte` です。
- アプリは起動時に、GitHub に新しい版があるかだけを問い合わせます（通信できなければ何もしません）。絵コンテ・カット絵・Excel の中身を外に送ることはありません。
- ブラウザ版は、上のアドレスのページ以外とは通信しません（ページの設定で禁止しています）。

## 使い方

まず試すときは、右上の「**サンプル・テンプレート…**」で記入例一式（カット絵PDF・香盤表とカット表のExcel・絵コンテと香盤表の出力例）を保存し、
そのまま①〜④を通してみてください。空の香盤表・カット表のExcel（テンプレート）もここから保存できます。
「すべてZipで保存…」で、記入例（横・縦）とテンプレートを1つのZipファイルにまとめて保存できます。

1. **カット絵用紙を作る**：右上でページ数と種類（**横** / **縦 9:16**）を選び、「カット絵用紙を作成…」で用紙PDFを作ります。
   - 縦 9:16 は縦型動画（ショート動画・縦型ドラマ）用です。用紙はどちらもA4横で、描く枠の形だけが違います。
2. **描く**：1ページに1カットずつ描き、右のマーク欄を塗って番号を指定します。
   - 例：`2-3` なら S一=2、C一=3。`12-5a` なら S十=1、S一=2、C一=5、枝=a（枝は追加カットのときだけ）
   - 印刷して使う場合は、**A4横・実際のサイズ（100%）**で印刷します。「用紙に合わせる」にすると縮小されます。
3. **① カット絵PDFを読み取る**：自動で番号を読み取ります。
4. **② 確認する**：黄色の「要確認」の行だけを確認します（「要確認・エラーだけ表示」で絞り込めます）。
   - 番号が正しい → 「この番号で確定」（Enter）
   - 番号が違う → 番号を修正（アプリ版はダブルクリックしてから。ブラウザ版はそのまま書き換えられます）
   - 絵コンテに入れないページ → 番号を空欄にする
5. **③ Excelを選ぶ**（省略可）：**香盤表**（シーンの情報）と**カット表**（カットごとの内容）を1つにまとめたファイル
   - 「テンプレート…」ボタンで、記入例つきのExcel（香盤表・カット表・記入方法の3枚のシート）を保存できます。
   - Googleスプレッドシートで書いた場合は「ファイル → ダウンロード → Microsoft Excel (.xlsx)」で保存して選びます。
6. **④ 絵コンテPDFと香盤表を書き出す**：番号順に並べ、シーンごとに改ページします。
   - 横の用紙で描いた場合：A4縦の表に1ページ6カット
   - 縦 9:16 の用紙で描いた場合：A4横に1ページ4カットを横に並べる（上から S・C・TIME / PICTURE / ACTION/SE / SCENARIO / NOTE）
   - 用紙の種類は読み取り時に自動で判別します（縦の用紙には右上マークの左に小さな「縦型の印」があります）。1つのPDFに横と縦が混ざっていると要確認になります。
   - 香盤表のExcelも一緒にできます（アプリ版は絵コンテPDFの隣に `〜_香盤表.xlsx` の名前で保存。書いた元のExcelは上書きしません）。

## 香盤表・カット表の書き方

1つのExcelに「**香盤表**」と「**カット表**」のシートを入れます（テンプレートはこの形。どちらか一方だけでも読めます）。
シートは名前で見分けます（名前が違っても、見出しに C の列があればカット表、場面・D/N などがあれば香盤表とみなします）。

**香盤表**（1行1シーン）は部の香盤表と同じ形です。#S・場面・L/LS・D/N・ロケ地・登場人物・備考を書きます。

- 登場人物の列は、見出しに役の名前、その上の段に役者の名前を書き、出るシーンに ○ を付けます（書き出す香盤表にそのまま引き継ぎます）。
- 別のファイルの香盤表を使うときは、そのシートをこのファイルにコピーし、シートの名前を「香盤表」にします。

**カット表**（1行1カット）：

| S | C | ACTION | SE | SCENARIO | TIME | 小道具 | カメラA | カメラB | 機材 | NOTE |
|---|---|---|---|---|---|---|---|---|---|---|
| 1 | 2 | 2人のミディアム | | 花子「ねえ、聞いた？」 | 5 | | 50mm | | | |
| | | 花子が振り向く | | 太郎「何を？」 | | | | | | |
| 2 | 1 | 倉庫の奥で男が拳銃を構える | 雨音 | | 3 | | | | | |
| 2 | | | | | | 拳銃 | 35mm | | 三脚 | |

- **S と C を書いた行** = そのカット
- **S も C も空欄の行** = すぐ上の行の続き。2行目以降のセリフや ACTION は下の行に書き足します
- **S だけ書いて C が空欄の行** = シーン全体（小道具・カメラ・機材・NOTE をそのシーンの全カットに入れる）
- ACTION と SE は、絵コンテではどちらも ACTION/SE 欄に入ります。SE は「SE：雨音」のように自動で頭に「SE：」が付きます。
  （ACTION/SE を1列で書いた以前のカット表もそのまま読めます）
- カメラA/B にはレンズを書きます。列を増やすときは「カメラC」のように見出しを付けます。
- 文字が欄に収まらないときは、自動で小さくします（最小5pt。それでも収まらなければ書き出し後に知らせます）。
- カット表とカット絵が食い違うと、書き出す前に知らせます。カット絵がないカットは PICTURE を空けて載せます。
- 見出しの列名で読むので、列の順番や開始行は自由です。

## NOTE欄に入る内容

| 内容 | 出どころ | 入るカット |
|---|---|---|
| 場面 / L/S / D/N、ロケ地 | 香盤表 | シーンの最初のカット |
| 備考 | 香盤表 | シーンの全カット |
| 小道具・機材・NOTE | カット表 | シーン全体の行はシーンの全カット、カットの行はそのカットだけ（足し合わせる） |
| カメラ＋レンズ | カット表 | 同上。ただしカットの行に書けばシーンの指定を置き換える |

- 追加カット（2-3a）は、元のカット（2-3）だけの指定を引き継ぎません。2-3a 用の指定は、カット欄に `3a` と書きます。
- 同じものは1回だけ載せます。小道具・カメラ・機材はカット表に書きます。香盤表に小道具・機材の列があれば、シーン全体の指定として一緒にまとめます。
  香盤表の備考に小道具などと同じものを書いた場合（「、」で区切ったもの）は、備考からは除きます。

## 書き出す香盤表（Excel）

絵コンテと同じ中身から作るので、2つが食い違うことはありません。

| シート | 1行 | 中身 |
|---|---|---|
| 香盤表 | 1シーン | 元の香盤表（タイトル・撮影日・場面・L/S・D/N・ロケ地・登場人物・備考）＋ カット数・時間（秒）・小道具・カメラ・機材（カット表からシーンごとにまとめたもの）。最後の行に合計 |
| カット一覧 | 1カット | 絵コンテから PICTURE を除いたもの（S・C・ACTION/SE・SCENARIO・TIME・NOTE）。最後の行に時間の合計 |

- 直すときは、書いた元のExcel（香盤表・カット表）を直して書き出し直します。書き出した香盤表を③で選ぶと、元のExcelを選ぶよう知らせます。

## 読み取りの仕組み

読み取りにAIは使わず、マークシートと同じ画像処理で行います。設計図（座標）は `ekonte/layout.py` の1か所で管理し、用紙PDFと読み取りの両方がそこを参照します。

1. 四隅の黒い四角を探し、**射影変換**で傾き・ずれ・縮小を補正する
2. 左上の**向き判定ドット**で、上下逆や90°回転を判定する
3. 各マークの中心部の濃さで「塗った・薄い・未記入」を判定する（薄い・複数・未記入は要確認）
4. 描画枠を座標で切り出す

## 開発

```bash
# Mac（書類フォルダが iCloud 同期の場合、Python環境は必ず iCloud の外に作る ※下記）
# Python 3.10 以上が必要（Mac に最初から入っている python3 は 3.9 なので、uv などで 3.11 を入れる）
~/.local/bin/uv python install 3.11
"$(~/.local/bin/uv python find 3.11)" -m venv ~/.venvs/ekonte
~/.venvs/ekonte/bin/pip install -r requirements.txt
~/.venvs/ekonte/bin/python app.py
```

コマンドだけで使う場合：

```bash
python -m ekonte.sheet カット絵用紙.pdf 20 [縦]                 # 用紙を作る（縦 = 9:16）
python -m ekonte.omr カット絵.pdf 出力フォルダ                    # 読み取り → 2-3.png など
python -m ekonte.compose 出力フォルダ 絵コンテ.pdf --excel 香盤表・カット表.xlsx --kouban 絵コンテ_香盤表.xlsx [--format 縦]
python -m ekonte.templates 香盤表・カット表.xlsx [空]             # 書き込むExcelを作る（空 = 記入例なし）
python -m ekonte.sample サンプル [出力例]                        # 動作確認用の記入例PDF（出力例 = 絵コンテ・香盤表の出力例）を作る
```

### アプリにする

| OS | 手順 | できるもの |
|---|---|---|
| Mac | `./build_mac.sh` | `~/ekonte-build/dist/Ekonte.app` |
| Windows | `build_windows.bat`（Windows上で実行） | `%USERPROFILE%\ekonte-build\dist\Ekonte\Ekonte.exe` |
| 全部 | `ekonte/__init__.py` の `__version__` を上げてコミットし、同じ番号のタグ（例 `v0.2.0`）を push | Releases に Mac（Apple シリコン・Intel）・Windows のzip、GitHub Pages にブラウザ版 |
| 全部（公開しない） | GitHub の Actions で「build」を Run workflow | Artifacts に同じzipとブラウザ版 |

- 動作確認：`Ekonte --selftest サンプル/カット絵_記入例_スキャン.pdf 出力.pdf`（画面を出さずに読み取り→絵コンテ・香盤表の書き出し→同梱サンプルの保存）
- Mac で作ったアプリは、作ったMacと同じ種類のCPU（Apple Silicon か Intel）でだけ動きます。
- 署名をしていないため、他のパソコンで初めて開くときは上の「ダウンロード」の手順で開きます。

### ブラウザ版

画面（`web/`）だけがアプリ版と別で、読み取り・Excel・絵コンテの組み立ては同じ `ekonte/` の Python を、
ブラウザで動く Python（[Pyodide](https://pyodide.org/)）の上でそのまま動かしています（入口は `ekonte/web.py`）。

```bash
~/.venvs/ekonte/bin/python web/build.py                    # dist-web/ に組み立てる（そのまま GitHub Pages に置ける）
node web/test_engine.mjs dist-web /tmp/web-test            # ブラウザ版の中身を Node で動かし、記入例を通す
~/.venvs/ekonte/bin/python web/compare.py dist-web /tmp/web-test   # デスクトップ版の Python と結果が一致するか比べる
```

- 手元で開くときは、`dist-web/` を `.mjs` を `text/javascript` で返すサーバーで配信します（ファイルを直接開いても動きません）。
- 公開はアプリと同じく、タグを push したときに GitHub の自動ビルドで行います（アプリとブラウザ版の確認が両方通ったときだけ、両方を公開）。
- 部品（Pyodide・numpy・Pillow・pypdfium2・reportlab・openpyxl など）は `web/vendor.json` に場所と指紋（sha256）を固定しています。
  `web/build.py` は指紋が一致したものだけを使い、ブラウザも読み込むときにもう一度照合します。
  部品を更新するときは、版・場所・指紋をまとめて書き換え、上の比較が通ることを確かめます（Dependabot は見てくれません）。
- 初めて公開するときだけ、GitHub のリポジトリで次の2つを設定します。
  1. Settings → Pages → Build and deployment の Source を「GitHub Actions」にする
  2. Settings → Environments → github-pages → Deployment branches and tags に、タグ `v*` を追加する

### iCloud の注意

書類フォルダが iCloud Drive と同期されていると、iCloud が `.venv` など「.」で始まるフォルダの中身に**非表示フラグ**を付け直します。
Qt は非表示のファイルを読み飛ばすため、「Could not find the Qt platform plugin」で起動できなくなります。
Python環境（`~/.venvs/ekonte`）とビルド作業（`~/ekonte-build`）をホーム直下に置いているのはこのためです。

```
app.py                 起動用
ekonte/
  layout.py            カット絵用紙の設計図（座標。横・縦の描画枠と縦型の印）
  sheet.py             カット絵用紙PDFの生成
  omr.py               マークの読み取り・カット絵の切り出し
  excel_import.py      香盤表・カット表（1つのExcel）の読み込み
  templates.py         書き込むExcel（香盤表・カット表・記入方法）の生成。香盤表は 香盤表_テンプレート.xlsx（部の形式）を使う
  compose.py           絵コンテPDFの組み立て（横 = 表のレイアウト、縦 = 4カット横並びのレイアウト）
  kouban.py            一緒に書き出す香盤表（Excel）
  gui.py               画面（アプリ版）
  web.py               ブラウザ版の入口（ブラウザから届いたファイルを上の処理に渡す）
  fonts.py             埋め込みフォント（BIZ UDゴシック）
  sample.py            動作確認用の記入例の生成
  samples.py           アプリに同梱するサンプル・テンプレートの一覧（ekonte.spec と web/build.py もここを見る）
web/
  index.html・style.css・app.mjs   画面（ブラウザ版）
  worker.mjs・engine.mjs           ブラウザの中で Python を動かす部分（画面が固まらないよう別の流れで動かす）
  vendor.json          ブラウザ版に入れる部品と指紋
  build.py             ブラウザ版の組み立て
  test_engine.mjs・compare.py      動作確認（デスクトップ版と結果が一致するか）
resources/fonts/       BIZ UDゴシック（SIL Open Font License, OFL.txt）
香盤表_テンプレート.xlsx  部の香盤表（テンプレートの土台）
サンプル/              記入例PDF・スキャン例PDF・出力例（絵コンテPDF・香盤表）・香盤表の記入例（記入例の土台）
```
